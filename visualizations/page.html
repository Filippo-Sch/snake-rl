How these replays were made
  • Each panel replays held-out test episode 0. Episodes were not selected by outcome. Native trajectories use the original 500-board batch and test stream 3; Classic uses its independent game-0 test stream.
  • Actions come from the six final checkpoints, using the original inference adapters and environments. No training, guidance, altered collision rules, or scripted paths are used.
  • The small inset is the exact observation passed to the policy. The highlighted region on a partial board is visible to the agent; the rest is shown only to the spectator.
  • Playback speed changes only presentation. Full Classic freezes after its episode ends while the partial policy continues. A repeated physical state is marked as a deterministic cycle.
  • These are illustrative trajectories. The report's aggregate scores use 500 episodes per policy and configuration and one training seed. All 2,000 native DQN records plus both displayed Classic records were compared with the original evidence.
